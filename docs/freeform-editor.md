# 自由编辑器

本文描述当前自由编辑器的 v17 场景树契约和用户可见行为。自由编辑器默认使用浏览器本地存储；配置 `VITE_API_BASE` 后使用远程账号、草稿和图片服务。两种存储模式共享同一份场景树和编辑器状态机。

## 文档模型

自由编辑文档固定使用 `documentVersion: 17`。每个页面有自己的尺寸、背景和递归 `nodes`，节点可以是叶子或组合组：

```json
{
  "documentVersion": 17,
  "activeSlideId": "slide-1",
  "slides": [{
    "id": "slide-1",
    "name": "Page 1",
    "width": 1080,
    "height": 1440,
    "background": { "type": "solid", "color": "#ffffff" },
    "nodes": [{
      "id": "group-1",
      "name": "标题组",
      "type": "group",
      "x": 240,
      "y": 180,
      "rotation": 0,
      "scale": 1,
      "locked": false,
      "hidden": false,
      "children": []
    }]
  }]
}
```

叶子类型为 `text`、`image`、`shape`、`line` 和 `path`（v15）。叶子使用父级坐标系中的 `x/y`、`width/height`、顺时针 `rotation` 和统一 `scale`。组只有原点、旋转、统一缩放和子节点；组的视觉边界由所有后代节点的世界坐标边界计算，不能把旋转后的轴对齐外框当作本地几何。

编辑器限制如下：

- 页面尺寸为 128 到 4096 px，最多 500 个页面。页面尺寸里的常用比例是 1:1、3:4、4:3、9:16、16:9、2.35:1（公众号首图，1800×766）和 A4（1240×1754）。
- 单页最多 5000 个场景节点，递归深度最多 32 层。
- 后代世界有效缩放必须在 `1e-4` 到 `1e4` 之间。
- 组只支持统一缩放；叶子仍可按宽度和高度分别编辑。
- 所有矩阵运算保持浮点精度，属性面板只在显示时保留两位小数。

## 图片裁剪与取景

独立 `image` 节点和 `shape` 的图片填充都保存一份取景值：

```json
{
  "fit": "cover",
  "framing": {
    "focusX": 0.5,
    "focusY": 0.5,
    "zoom": 1
  }
}
```

`focusX` 和 `focusY` 的范围是 0 到 1，`zoom` 的范围是 1 到 4。默认值表示图片居中且不额外放大。`cover` 始终覆盖完整画框；焦点靠近边缘时会按实际图片尺寸夹紧，不会露出空白。`contain` 保持原来的完整图片显示方式，不应用取景位移和缩放。

独立 `image` 节点选中后，从属性面板点击“裁剪”或双击图片进入 PowerPoint 式裁剪。拖动画面可以移动原图，八个黑柄调整裁剪框；方向键每次移动 1 个本地像素，按住 `Shift` 时移动 10 个。顶部“比例”菜单提供原图、1:1、4:3、3:4、16:9 和 9:16，预设只调整当前裁剪框，之后仍可自由拖柄。点击“完成”、按 `Enter`、按 `Escape` 或点击画布外部都会保留结果；一次操作只写入一条历史记录，没有改动时不写历史。

矩形、圆形和三角形的图片填充仍从属性面板进入“调整取景”，也可以双击进入。鼠标拖动图片，底部滑杆和加减按钮调整缩放；点击“完成”保存，点击“取消”或按 `Escape` 恢复进入前的值。切换页面、项目或账号时，独立图片裁剪会先完成，形状取景则取消。

矩形、圆形和三角形共用取景算法，只改变画框的裁切轮廓。裁剪或取景期间普通工具栏和属性面板不可操作；在 520px 及以下宽度，两侧面板会临时收起，退出后恢复。

## 富文本片段

`text` 节点可以带一个可选的 `spans` 数组，为 `text` 内的字符区间叠加局部样式：

```json
{
  "type": "text",
  "text": "重点加粗内容",
  "spans": [
    { "start": 0, "end": 2, "bold": true },
    { "start": 2, "end": 4, "color": "#d92d20" }
  ]
}
```

- 每个片段标记左闭右开区间 `[start, end)`，至少带一种样式：`bold`（只接受 `true`）、`color`（六位十六进制文字色）、`highlight`（六位十六进制高亮底色，v16）、`underline`（只接受 `true`，v16）；`highlight` / `underline` 只在 v16 文档里合法。
- 规范片段按 `start` 升序、互不重叠、`0 ≤ start < end ≤ text 长度`，且数组非空；不满足时整个文档被拒绝，不会静默修补。
- `node/update-style` 的 `spans` 补丁整体替换片段数组（传 `[]` 清空）；改动 `text` 时已有片段按公共前后缀差异自动保留、收缩或丢弃，编辑错别字不会破坏样式。
- 编辑器内双击文本进入编辑后选中一段文字，设置面板里会出现「文字片段」：加粗、下划线（选中的字都已加粗 / 加下划线时按钮显示按下，再点取消）、清除样式，以及标色和高亮两排预设色块。新样式叠加在选中文字已有的样式上（给加粗的词加高亮，它仍然加粗），相邻且样式相同的片段自动合并。已保存的片段以列表展示，可单独删除。片段在画布、页面缩略图、PNG 导出和 MCP 无头渲染中一致呈现；渐变文字里的标色、高亮片段改用纯色字形，免得被高亮底色盖住。

## 花字与文字效果

v17 起文字可以带一个效果 `effect`（一段文字一种，`src/freeform/textEffects.ts`）：

```json
{ "type": "text", "text": "限时上新", "effect": { "type": "background", "color": "#18181b", "amount": 40, "radius": 30 } }
```

- 十种效果：`neon` 发光、`outline` 字外描边（贴纸字）、`hollow` 镂空、`splice` 错位（镂空字叠在错开的实心字上）、`offset` 硬投影、`echo` 回声（两层渐淡的重影）、`glitch` 故障（左右错开的双色）、`extrude` 立体、`background` 底色（每行文字后面一块色块，长短跟着文字）、`marker` 荧光笔（每行下半截一道色带）。`color` / `color2` 是 `#RRGGBB`，`amount`（0–100，50 为默认）是按字号比例算的强度或大小，`angle`（0–360，0 向右、90 向下）是方向，`radius`（0–100）是底色的圆角。效果的大小都按字号比例算，同一个效果在 30px 的小字和 120px 的标题上看起来一样。
- 画法：除了镂空，效果都画在文字下面一份同样排版的「效果层」上（`.freeform-text-effect`，不挡点击、可以超出文字框），所以渐变字也能干净地加投影、发光、描边；镂空和错位把文字本身变成只剩轮廓（颜色是文字自己的颜色，渐变字取渐变的第一个颜色）。画布、缩略图、PNG/JPG/PDF/长图导出和 MCP 渲染一致。
- 文字面板的「花字」是 16 套现成的样子（霓虹青、霓虹粉、贴纸白边、糖果描边、镂空、错位、复古投影、回声、故障、立体、黑底标签、黄色底块、荧光笔、日落渐变、极光渐变、金色，`src/freeform/textStyles.ts`），每块在它最合适的底色上预览。选中文字时点一下，所有选中的文字一起换成这个样子（填充、效果、加粗一起设好，原来的描边和阴影去掉），记一步撤销「套用花字」；没选文字时插入一段这个样子的标题。
- 设置面板的「效果」区：第一排是「无」和十种效果的小样，点一个就换上（新效果按文字颜色挑默认颜色：深色字配白色描边、浅色字配黑色底块等），下面是这个效果的颜色（故障有两种颜色）、大小（强度、粗细、偏移、厚度、扩展或高度）、方向（错位、投影、回声、立体）和圆角（底色）。复制粘贴样式会带上效果。

## 视觉外观

v6 起所有叶子都可以带可选外观字段，v7 再增滤镜、混合模式、虚线线帽与新形状，v8 增多段渐变与文字描边，v9 增竖排文字，缺省即默认样式：

```json
{
  "type": "shape",
  "shape": "star",
  "cornerRadius": 32,
  "opacity": 0.85,
  "shadow": { "color": "#101828", "blur": 24, "offsetX": 0, "offsetY": 8 },
  "filter": { "brightness": 1.1, "blur": 4 },
  "blendMode": "screen"
}
```

- `opacity`（0–1）作用于任何叶子；`shadow` 为 `{ color, blur(0–400), offsetX(-1000–1000), offsetY(-1000–1000) }` 投影。
- `text` 叶子额外支持 `lineHeight`（0.5–4 无单位倍数）、`letterSpacing`（-50–200 px，负值收紧）、`italic`（只接受 `true`）和 `vertical`（只接受 `true`，v9 起竖排，`writing-mode: vertical-rl` 自上而下、自右向左）。
- `shape` 叶子额外支持 `cornerRadius`（0–2000 px，呈现于矩形）；形状枚举在 v7 扩展为 `rect`、`ellipse`、`triangle`、`star`（五角星）和 `hexagon`（六边形），后两者仅 v7 及以上接受。
- `line` 叶子额外支持 `dash`（1–500 px 虚线长度，虚线与间隔等长）和 `cap`（`round`/`butt`/`square` 线帽，缺省圆头）。
- v7 起所有叶子支持 `filter`（`{ brightness?, contrast?, saturation?, blur? }`，各 0–3 倍、模糊 0–100 px，至少一键）与 `blendMode`（16 种 CSS 混合模式）。
- v8 起 `ColorPaint` 渐变支持多段式 `{ type: 'linear-gradient', stops: [{ offset, color }], angle }`（2–8 个色标，offset 在 0–1 内严格递增），可用于页面背景、文字填充与形状填充；旧两段式 `{ from, to, angle }` 继续合法。`text` 叶子额外支持 `stroke`（`#RRGGBB` 描边色）与 `strokeWidth`（0.5–100 px 描边宽度），仅 v8 及以上接受。
- v11 起 `shape` 填充支持 `{ type: 'transparent' }` 无填充（纯描边轮廓形状），仅 v11 及以上接受；属性面板填充区提供「透明」模式，与纯色、渐变、径向、图片并列。新插入的形状描边宽度默认为 0，切到「透明」后需自行调大描边宽度才能看到轮廓。
- v14 起 `line` 叶子支持多段线顶点 `points`（`[{ x, y }×2–64]`，可选键，仅 v14 及以上接受）：坐标为节点盒内局部坐标（0≤x≤width、0≤y≤height），节点盒即顶点包围盒（建议留出描边宽度余量），首末点即线段两端并承载端点装饰；`node/update-geometry` 改 width/height 时顶点按比例缩放（Figma 语义），移动 x/y 不影响顶点；`node/update-style` 的 `points` 补丁整体替换顶点列表（MCP 可用，历史标签「调整顶点」）。渲染为顶点精确落点的 `<polyline>`（圆角连接），端点处的箭头/圆点装饰不被盒子裁剪。缺省 `points` 的线段保持「盒内水平线段 + 旋转」的经典几何不变。
- 多段线顶点控点编辑：选中多段线后，每个顶点显示圆形控点——拖动控点移动该顶点（自动限制在节点盒内，一次撤销记为「拖动顶点」）；双击线段附近在该处插入新顶点（投影到最近线段，「添加顶点」）；双击控点删除该顶点（至少保留 2 个，「删除顶点」）。顶点拖拽走同一直播编辑管线：进行中不进历史，松手一次入账，Esc/失焦取消回滚。
- v13 起 `line` 叶子支持端点装饰 `startCap`/`endCap`（`'none'`/`'arrow'`/`'dot'`，可选键，仅 v13 及以上接受）：起点画箭头、终点画圆点等端点样式自由组合；缺省时终点装饰跟随 `lineKind`（`'arrow'` 即箭头、`'line'` 即无，起点始终无）。属性面板线条「描边」区提供「端点」起点/终点两组三档控件（无/箭头/圆点），显示的是生效值，选回 lineKind 默认值时会清掉显式键保持文档精简。箭头与圆点以描边宽度为单位缩放（与既有箭头一致），画双向箭头、标注引出点不再需要摆两个箭头线对齐。
- v15 起新增 `path` 叶子画任意矢量图：`d`（SVG 路径数据，`M/L/H/V/C/S/Q/T/A/Z` 及小写相对命令，以 `M`/`m` 开头，最长 20000 字符，语法外的内容整份拒绝）写在 `viewBox`（`{ x, y, width, height }`，宽高为正）坐标系里，渲染时铺满节点盒；`fill` 为 ColorPaint 或 `{ type: 'transparent' }`（没有图片填充），`stroke` 为 `#RRGGBB`，`strokeWidth` 用 `viewBox` 单位（0–10000，0 即不描边），可选 `dash`（`viewBox` 单位）、`cap`、`join`（`round`/`miter`/`bevel`，缺省圆滑）、`fillRule`（`nonzero`/`evenodd`）与通用外观键。图形按节点盒在像素里重画（圆弧换算成拉伸后的椭圆），再用均匀的描边描出，盒子改了宽高比描边也不会一边粗一边细；面板和对象工具条里的描边宽、虚线以页面像素显示和输入。从四角拖动保持图形比例，从四边拖动可以拉伸。换图形用 `node/update-content` 的 `{ d, viewBox }`。
- v16 起页面背景可以是图片：`{ type: 'image', src, fit, framing }`，和图片节点一样按 `fit`（`cover` 铺满裁切、`contain` 完整显示、留空处透明）与 `framing`（取景焦点和缩放）摆放。图片画在页面所有节点下面、画布内容区里，所以混合模式会和它混合；不挡点击，点空白处照样取消选择、开始框选。设置面板「页面」的背景多了「图片」模式：选一张图片（长边超过 2400px 先缩小），之后可切换填满 / 适应、「调整取景」（和调整图片节点的取景同一套：拖动平移、滑杆缩放、完成后记一步撤销）、「重置取景」、「替换图片」和「清除图片」。选中一张图片时，设置面板和右键菜单里的「设为背景」把它变成页面背景并删掉原图，记一步撤销。背景图片和节点里的图片一样参与图片租约、素材引用计数、本地引用导出和远程保存时的上传。
- 元素面板的「图标」一栏是内置的 97 个线性图标（[Lucide](https://lucide.dev)，ISC 许可），可按中英文名或关键词搜索；点一下插入为 `path` 节点（24×24 的 `viewBox`、2 单位描边、无填充、圆头圆角，盒子取页面短边的 15%），图层名就是图标名。图标数据由 `scripts/icons/build-icon-library.mjs` 生成到 `src/freeform/iconLibrary.ts`，MCP 的 `list_icons` 与 `dingcard://icons` 用的是同一份。
- v12 起 `ColorPaint` 支持径向渐变 `{ type: 'radial-gradient', stops: [{ offset, color }] }`（2–8 个色标，与多段线性渐变同一套色标规则，无角度键），渲染为以节点盒中心为圆心、最远角为半径的 `radial-gradient`，可用于页面背景、文字填充与形状填充；仅 v12 及以上接受。属性面板填充区提供「径向」模式（与纯色、渐变并列），色标编辑与线性渐变同一套控件，径向下没有角度滑杆；「渐变」与「径向」互切时保留全部色标。
- 字段缺失、越界或包含额外键时整个文档被拒绝；补丁里传 `null` 恢复默认（阴影/滤镜/混合/虚线清除）、`italic: false` 取消斜体。
- 属性面板「外观」区提供不透明度、圆角、阴影、混合模式与滤镜编辑（亮度/对比度/饱和度/模糊，可添加/清除）；「文字」区提供行高、字距、粗体、斜体、竖排与描边（颜色/宽度/清除）；渐变编辑提供「添加色标」进入多段编辑（每个色标一行：色块、色值、位置百分比和删除「−」，最少 2 个、最多 8 个），线性渐变另有角度滑杆（径向渐变没有）；线条的「描边」区提供虚线、线帽与端点（起点/终点的无/箭头/圆点）。外观在画布、页面缩略图、PNG 导出和 MCP 无头渲染中一致呈现；三角形、五角星与六边形使用 `drop-shadow`，混合模式限制在画布 artwork 内（`isolation: isolate`）。

## 整套换风格

工具栏的「风格」面板只做一件事：给整套卡片的所有页面一起换样子，每次选择记一步撤销（历史里是「更换配色」「更换字体组合」），参照 Canva 的风格（Styles）和 PowerPoint / WPS 的设计变体。逻辑在 `src/freeform/restyle.ts`，编辑器和 MCP 用同一个动作 `document/restyle`，文档版本不变（只改已有的颜色和字体字段，文字效果的颜色一起换）。改某一个颜色或字体在设置面板里做（见下文「全部替换」），风格面板里不再重复列出整套的颜色和字体。

- 「搭配」：8 套现成的搭配（杂志、清新、森系、甜美、文艺、极简、夜读、霓虹夜），每套是一组配色加上和它相配的字体组合，块上用这套的底色、标题字体、强调色和正文字体画出「标题」「正文内容」，点一下两样一起换，一步撤销。
- 「配色」：10 套配色（纸墨、海盐、松林、莓果、奶咖、黑白、夜航、霓虹、墨黑、蓝图），每套是页面底色、文字色和两个强调色，色块上画着「Aa」和强调色圆点。套用时，整套里铺得最多的页面底色换成新底色，和底色深浅差得够多的文字色里用得最多的那个换成新文字色（所以深色结尾页这种反过来的页面仍然是反的）；其他接近中性的颜色（浅灰卡片、细线、灰字）按它原来在底色和文字色之间的深浅位置，在新底色和新文字色之间取色；有自己颜色的（红色标签、霓虹青、文字效果的颜色）按占的面积依次换成强调色。最后把因此看不清的字（和它下面最近的不透明色块或页面比；带底色块效果的字和底色块比，字外描边和字反差够的不动；对比度低于 `check_document` 的门槛：大字 3:1、其余 4.5:1）在色相不变的前提下调深或调浅，图片和渐变上的字不动。
- 「字体组合」：6 组（现代黑体、杂志宋体、书卷宋体、手写文楷、海报小薇、系统苹方），每组一个标题字体和一个正文字体，按钮用标题字体写组名，下面用各自的字体写「标题字体 + 正文字体」（两个一样时只写一个）。按字号分配：整套文字按字数取中位字号作为正文字号，字号不小于它 1.4 倍的文字用标题字体，其余用正文字体。导入的字体排在后面，用它自己的字体写名字，点一下整套文字都换成它，右边的 × 从字体库删掉；最后是「导入字体」（见下文「导入字体」）。

### 全部替换

改颜色和字体的地方顺手就能整套一起改，不用另找入口（参照 Canva 改色后的「全部更改」）：

- 取色器（设置面板和对象工具条里所有的颜色）最上面一排是「本设计用色」：整套用到的颜色，按占的面积排序，最多 12 个，点一个就用它；和下面的常用色之间有一条分隔线。打开取色器后改了颜色，底部出现「● → ● 全部替换」：把整套里原来那个颜色（打开时的颜色）都换成现在这个，一步撤销。
- 字体：在设置面板或对象工具条里给选中的文字换了字体，设置面板的字体下拉框下面出现「全部替换」，把整套里还用原来字体的文字都换成新字体；换了选中对象就消失。

## 导入字体

字体下拉框（设置面板和对象工具条）最后一项是「导入字体…」，风格面板的字体组合下面也有「导入字体」按钮，选 TTF、OTF、WOFF 或 WOFF2 文件（最大 40 MB）：

- 名字取字体文件里自己写的名字（中文名优先，再是英文名；样式不是常规体时接在后面，如「阿里巴巴普惠体 Bold」），读不出来（WOFF2）就用文件名；和内置字体重名时后面加「 2」。同名的字体再导入一次会替换原来的文件。
- 字体存在这个浏览器里（IndexedDB 的 `dingcard.fonts`，`src/freeform/fontLibrary.ts`），打开编辑器时注册到页面上，画布、页面缩略图、项目卡片和导出（PNG / JPG / PDF / 长图，整份字体文件嵌进去）都用它。从下拉框导入时直接用到选中的文字上。文字记的是 `'字体名', sans-serif`，在没有导入这个字体的浏览器里（或 MCP 渲染时）退回默认无衬线字体。
- 不是字体的文件、浏览器读不了的字体文件、太大的文件都会提示原因，不会存下来。

## 迁移和持久化

读取文档时，v1/v2 平面 `slides[].elements` 会先复制到节点树；v3 场景树会为独立图片和形状图片填充补上默认取景。所有旧格式最后都经过严格归一化，并把 `documentVersion` 写成 17。输入对象不会被原地修改。v4 及以上文档必须显式带有合法取景值，字段缺失、越界或包含额外键时会被拒绝，不会静默修补。

保存时本地和远程存储都产出 v17 文档，读取时接受 v1–v17。远程保存会在提交前递归处理隐藏节点中的图片引用，历史 Data URL 会上传并替换为托管 URL；图片引用扫描不会因为节点隐藏而跳过。远程保存响应经过同一严格边界后才回到工作区。后端草稿 API 仍把 `document` 当作不透明 JSON，v1–v16 到 v17 的迁移由前端存储适配层完成。

## 图层面板

设置面板有“属性”“图层”“历史”三个标签，从工具栏最下面的“图层”可以直接打开图层标签。图层标签使用可访问的递归树：

- 单击选择节点；`Shift`、`Ctrl`/`Cmd` 可在同一父级内多选。
- 组可展开、折叠和重命名；树行保留层级、当前选择和继承状态。
- “组合”要求至少两个同级节点；“解组”按一层提升子节点。锁定、隐藏、跨父级或超出深度/数量限制的操作会被拒绝且不产生历史记录。
- 树行的锁定和隐藏按钮只改变节点自身状态。父级锁定或隐藏会向后代继承；后代仍可在面板中查看自身状态和继承原因。
- 树键盘支持方向键、`Home`、`End`、`Enter`、空格、`F2` 和 `Alt + ↑/↓`：`Enter` 单选，空格切换多选，`F2` 重命名，左右键展开/折叠，`Alt + ↑/↓` 调整同级顺序。画布双击组内节点或对已选组按 `Enter` 可进入编辑作用域，`Escape` 逐层退出；文本编辑和弹层会先消费自己的 `Escape`。

常用快捷键：

| 操作 | 快捷键 |
|---|---|
| 组合 | `Ctrl/Cmd + G` |
| 解组 | `Ctrl/Cmd + Shift + G` |
| 复制/粘贴 | `Ctrl/Cmd + C` / `Ctrl/Cmd + V` |
| 撤销/重做 | `Ctrl/Cmd + Z` / `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` |
| 删除 | `Delete` 或 `Backspace` |
| 方向微调 | 方向键；`Shift` 加大步长 |

## 变换和剪贴板

画布指针、框选、吸附、方向微调、对齐和分布都在页面世界坐标中计算，再通过父级世界矩阵转换回本地坐标。组作为一个逻辑单位移动、旋转、缩放和对齐，组内子节点的相对变换保持不变。有效锁定节点不会出现变换控件，也不能被键盘或指针修改。

复制内容在内存中保留来源父级的世界矩阵。粘贴到另一个作用域时，目标节点的世界位置等于来源世界位置加页面偏移 `(16, 16)`，随后转换为目标父级本地坐标；嵌套 ID 会递归重建且不会与文档现有 ID 冲突。非法有效缩放会拒绝整次粘贴，不会破坏剪贴板。

系统剪贴板里的图片（截图、网页上「复制图片」得到的图）在画布上按 ⌘V（其他系统 Ctrl+V）直接粘贴成图片，放进当前页正中并像其他插入一样错开，一次最多 10 张。这条路径靠浏览器的 `paste` 事件：按下平台自己的粘贴快捷键时编辑器不拦截按键，由 `paste` 事件判断——带图片就插入图片，不带就粘贴编辑器里复制的对象；浏览器没发 `paste` 事件时（比如 Mac 上按 Ctrl+V）照旧直接粘贴对象。在编辑器里复制或剪切对象时，系统剪贴板同时写入其中的文字（没有文字时写入空文本），所以之后粘贴拿到的是刚复制的对象，不会被更早复制的截图抢先。焦点在输入框或正在编辑的文字里时，粘贴照常是文字。

## 图片、导出和历史

本地模式把图片暂存为会话引用，保存副本时物化为 Data URL。远程模式把图片上传到 `/api/images`，以托管 URL 写入草稿，并通过 retain/租约机制续期。服务端只回收“租约已过期且没有任何草稿引用”的图片，因此隐藏组中的图片也会保留；集成测试使用 `IMAGE_LEASE_MS=500` 加速验证，生产默认租约不变。

PNG 导出只渲染画布艺术层，不包含选择框、旋转手柄、图层树或属性面板。隐藏节点及其后代不产生像素，锁定节点仍参与渲染。导出尺寸始终等于页面逻辑尺寸（乘以导出倍率），与浅色/深色主题和预览缩放无关。生成导出前会等待当前导出容器内的图片完成解码；图片失败或超时会中止下载并保留当前页面。

工具栏「导出选项」提供导出设置（与参考线显隐等视图偏好一同持久化，跨会话记忆）：格式 PNG/JPG（JPG 不支持透明，自动衬白底，另提供 50–100% 质量滑杆）、倍率 1x/2x（2x 输出双倍分辨率，如 1080×1440 页导出 2160×2880）；文件名后缀随格式变化（`.png`/`.jpg`），打包导出同样应用当前设置。

## 界面布局

- 顶栏只有一条：左边是返回工作台、项目名称（点击即可改名）和自动保存状态；中间是撤销、重做、页面尺寸，以及显示标尺、显示参考线、对象吸附三个开关（图标按钮，按下表示打开，选择记在视图偏好里）；右边是界面语言、深浅色、账号和「导出」。「导出」展开后选格式（PNG、JPG、PDF；JPG 和 PDF 可调质量）和倍率（1x/2x），再「下载当前页」；PNG、JPG 可以「打包下载全部 N 页」成 ZIP，或「拼成一张长图」（所有页从上到下拼成一张，每页居中在最宽页面的宽度上，JPG 衬白底；超过 32000 像素时自动降低倍率并提示，降到 0.5x 仍放不下就提示改用打包下载）；PDF 是「下载全部 N 页」，所有页放在一个文件里，每页和卡片一样大（96 px 合 1 英寸，1080×1440 的页面是 810×1080 pt），各页尺寸不同时各自保留、不提示。PDF 由 `src/exportPdf.ts` 按每页 JPEG 直接写出，不依赖第三方库，MCP 用同一份代码。
- 自由编辑与 Markdown 卡片是两个独立入口（`#/edit/canvas`、`#/edit/md`），顶栏不再有两套系统的切换。
- 主要操作都在左、上、右三边，画布下方不放东西：左边从外到内是工具栏、插入面板（打开时）和页面列表，画布上方一行对象工具条改当前对象，右边的设置面板只在需要时打开，缩放单独浮在画布右下角。页面列在左侧、缩放在角落，参照 PowerPoint / WPS、Keynote 和 Figma 幻灯片；标尺、参考线这类视图开关放在顶栏，一眼能看到。
- 左侧工具栏：模板、风格、文字、图片、元素，最下面是页面和图层（「页面」显示或收起页面列表）。前五个各自在工具栏旁边展开同一种宽面板（一次只开一个，点同一个按钮、面板右上角的关闭或 Esc 收起，Esc 后焦点回到工具栏按钮），插入后面板不收起，方便接着加。模板面板按尺寸分组（小红书套图、竖版海报、方图、横版封面、公众号首图、A4 印刷），每张按它自己的比例画出首页，下面是页数或比例，横版的占满一行，点一张在模板中心里放大查看，「浏览全部模板」直接打开模板中心（顶上一排按尺寸筛选）；风格面板见下文「整套换风格」；文字面板是「添加文本框」加上标题、副标题、正文三种默认样式，每一行按插入后的样子排版；元素面板是形状（矩形、圆形、三角形、五角星、六边形）和线条（直线、箭头）两组图块；图片面板可以上传图片直接放进当前页，也可以从素材库点选插入（按图片原始比例居中，不放大小图）。新插入的文字、形状、线条和图片都放在页面（或打开的组）正中；正中已经有对象时往右下错开一步（页面短边的 3%，1080 宽的页面是 32px），再有就再错一步，放不下时改往左上，连着加几个不会叠在同一个位置。
- 画布上方是对象工具条（`role="toolbar"`，`data-subject` 标明当前对象）：没选中对象时只有最右的「更多」，页面名称和背景在它打开的设置面板里；文字是字体、字号（− / + 按 12、14、16…240 这组常用字号走）、颜色（下面带色条的「A」）、粗体、斜体和三种对齐；形状是形状切换、填充、描边、轮廓粗细和矩形圆角，图片填充的形状换成「调整取景」；图片是裁剪和填满 / 适应；线条是颜色、粗细和末端箭头；图形是填充、描边颜色和描边粗细；多选可「编成一组」，组可「取消编组」。右端是透明度、位置（对齐与均分）、层级、复制一份、锁定和删除（锁定的对象只剩解锁），最后是「更多」。工具条从不滚动（滚动容器会裁掉颜色弹层和菜单），也始终只占一行，所以选中、取消选中都不会让画布跳动：舞台变窄时先收起菜单名（读屏名称保留），再收起透明度、对象名称、页面尺寸、颜色标签、文字对齐和字体（这几步按舞台宽度分段）；两侧面板都开着、窗口又不宽时仍放不下，工具条量一下自己，按需要依次收起「更多」的文字、位置和层级菜单、复制和锁定、次要的数值框（轮廓粗细、圆角、线宽、字号的 − / +）、删除，最后是对象名称，只收到放得下为止，舞台变宽后再展开（`data-fold` 记着收到第几步）。收起的设置在设置面板里都有，复制和锁定还在右键菜单和快捷键里。
- 设置面板默认不出现：点工具条的「更多」在右边打开它的「属性」页（宽度是窗口的 21%，在 256 到 304px 之间；里面的分段按钮、色标行和输入框都跟着面板宽度伸缩，不会被裁掉），点工具栏最下面的「图层」打开「图层」页，再点同一个入口或面板右上角的关闭就收起；开着还是收着记在视图偏好里（`panelOpen`），下次打开编辑器照旧。面板里是全部设置：没选中对象时是页面名称和背景（纯色、渐变、径向、透明）；选中对象后，顶部是一排对齐与分布图标（单个对象对齐到页面或所在组，均分需要三个及以上对象），下面依次是位置与尺寸、文字、填充、描边、外观和排列；数值框的标签放在框里（X、Y、W、H 用字母，旋转、圆角、不透明度、字号、行高、字距用小图标，鼠标停留显示全名）。「文字片段」只在选中一段文字时出现，给这段文字加粗或标色；已有的片段列在这里，可以逐个删除。颜色为透明时色块画成白底红斜线。图片取景和裁剪时，取消 / 完成等会话按钮浮在画布顶部，对象工具条隐藏但留着那一行，画布尺寸不变。
- 页面列表在工具栏（和打开的插入面板）与画布之间：缩略图从上往下排，下面是页面名称，当前页用蓝色描边；点击切换，上下拖动排序，双击名称重命名，最后是「新增页面」。每页右上角的「…」打开页面菜单（重命名、复制、删除、上移、下移、移到最前、移到最后），右键缩略图也是这份菜单；「…」在当前页上一直显示，其他页鼠标移过去才出现，用键盘打开时焦点落在第一项，方向键移动，`Escape` 关闭并回到「…」。切换页面后列表自动滚到当前页（只滚列表本身）。插入面板开着时页面列表仍在旁边，可以一页一页地点选再插入图片；窗口不超过 1100px 时缩略图变小。列表顶部是页数和「收起页面列表」，收起后画布变宽，点工具栏的「页面」再打开，开着还是收着记在视图偏好里（`pagesVisible`）；不论列表开着没有，`PageUp` / `PageDown` 都能翻到上一页、下一页。
- 画布铺满舞台。缩放浮在舞台右下角：「−」「百分比」「+」，点百分比回到适应画布（也可以按 ⇧1），缩放到选区用 ⇧2 或右键菜单。适应画布时页面下方留出缩放按钮的位置，不会被它压住。标尺默认关闭，打开后浮在画布上边和左边；参考线仍从标尺拖出，画成灰色虚线（虚线段在任何缩放下都是 4 个屏幕像素），对象吸到参考线上时用选中色的实线提示。拖动参考线时旁边显示它的位置（页面像素）；打开「对象吸附」时，离页面中心、页面边缘或某个对象的边和中线 6 个屏幕像素以内就吸过去，参考线和读数变成选中色，吸到页面中心时读数是「居中 · 540」。按住已有的参考线也会显示它的位置，不会挪动它。
- 页面名称：新页面存成 `Page N`、复制出来的存成 `原名 copy`，这些没人输入过的名字按页面现在的位置显示成「第 N 页」（英文界面是 `Page N`），排序、复制后跟着位置变；改过名的页面照原样显示，其副本的 ` copy` 后缀显示为「副本」。文档里存的名字不变，确认重命名时输入框里的名字没改也不记历史。
- 从桌面把图片文件拖到画布上，松手的位置就是图片中心（一次最多 10 张，依次错开 32px）；不是图片的文件会提示「这里只能放图片」。界面上不放说明文字和快捷键提示卡。
- 画布右键菜单的每一项在右侧标出快捷键（Mac 上是 ⌘C、⇧⌘V、⌥⌘C、⌘]、⇧2 这样的写法，其他系统是 Ctrl+C），快捷键 `aria-hidden`，菜单项的读屏名称仍是动作本身。

## 选中框

- 选中框是细蓝框加白色小方柄。单个对象有四角四边八个柄：从哪个柄拖就从哪边改尺寸，对边（边柄时是对边的中点）保持不动，按住 `Shift` 等比缩放；组合和多选只有四个角，从对角等比缩放。框在屏幕上窄于 56px 时不显示边柄，小于 36px 时只留右下角的柄。右下角的柄可以用键盘聚焦，其余柄只响应指针。
- 旋转和移动在选中框上方的白色小胶囊里（离页面顶部太近时挪到框下方）：按住旋转柄转动，`Shift` 以 15° 为步长；移动柄用来拖动不方便直接点中的对象（比如正在编辑的文字）。
- 拖动、缩放和旋转进行中，柄和胶囊隐去，框下方显示蓝色的「宽×高」或角度读数；间距标注和吸附线照旧。

## 自动保存

没有「保存草稿」按钮：每次编辑停下约 0.7 秒就写回当前项目，顶栏显示「保存中… / 已保存」，失败时显示「保存失败」和「重试」。第一次保存创建项目，之后都更新同一个 id；保存按顺序一个接一个发出，不会因为连续编辑建出两个项目。离开编辑器、打开另一个项目、退出登录或关闭页面时，排队中的修改会立刻发出。新建的空白文档和刚套用的模板在第一次编辑前不会生成项目。拖动、裁剪、取景等交互进行中不保存，结束后再保存最终结果；新项目第一次保存时，选中状态和进行中的裁剪保持不变。

没登录也一样自动保存：项目归这台设备的访客所有（存储里的所有者是 `local-guest`），存在浏览器本地，顶栏显示「已保存到本机」；部署了服务端时也不上传。登录或注册时会问一次要不要把这台设备上的项目和素材「放进账号」：逐个保存进账号后才从本机删除，中途失败的留在本机，可以重试；服务端部署时自由编辑的内嵌图片和 Markdown 的 `img:` 引用都会先上传。当时打开着的项目会在账号里继续打开。选择「先留在本机」后，这台设备没有新作品就不再追问，「我的项目」顶部留一行提示，随时可以再放进去。登录过期时没来得及保存的修改留在屏幕上，顶栏显示「登录后继续保存」，重新登录同一个账号后存回原来的项目；换了别的账号登录时，这些修改作为本机项目保留。

窗口宽度不超过 720px 时布局改为纵向堆叠：工具栏横排在最上方，画布舞台占满宽度（缩放仍在它的右下角），页面列表变成一行横排的缩略图（左右拖动排序），插入面板与（打开时的）设置面板依次排在下方，各自内部滚动；取景和裁剪时只保留画布。工具栏在 860px 以下横向滚动，不产生页面级横向溢出。

保存响应可能在实时指针手势期间返回。工作区使用统一历史入口和保存快照权威门：`pointerup` 只提交一次手势历史，`pointercancel` 恢复对应保存快照和已保存状态；旧草稿或旧用户的迟到响应不会改变当前作用域、选择或草稿身份。
